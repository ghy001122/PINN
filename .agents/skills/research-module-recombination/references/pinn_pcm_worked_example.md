## 4. Negative-Result Salvage

### PR #36

- Failed: stable patterned-transition span under the frozen ideal current clamp.
- Retained: stability evidence and candidate stability-boundary/branch-switching machinery.
- Not implied: global absence of patterns or failure of voltage-protocol physics.

### PR #37–#38

- Failed: direct-coordinate PINN contracts under their frozen architecture, data, and budget.
- Retained: M1 reference, Robin interfaces, conservation topology, control-volume metrics, and ledgers.
- Recombination: those assets enabled solver-projected latent methods without reinterpreting the direct-PINN failures.

### PR #39–#40

- Passed: low-rank state plus conservative projection can be accurate.
- Failed: neural mapper necessity relative to analytic A2/ridge in the prescribed-state benchmark.
- Retained: POD, projection, matched-budget evaluation, and a clear neural-admission gate.

### PR #41–#42

- Failed: a single-valued initialization-independent steady relation.
- New interface: explicit monotone voltage protocol and previous-state provenance.
- Passed: bounded protocol selection with sampled local stability and repeatable events.

### PR #43

- Failed: hard-gated heads' independent value and two-candidate coverage, despite ambiguity recall = 1.0 and certified false-unique = 0.
- Retained: full factorial contexts, leakage barriers, protocol-conditioned single-head baseline, and refusal diagnostics.
- Current lesson: a functional idea must still cover the physical candidate set; perfect ambiguity recall alone is insufficient.

The worked example shows the core rule: retain source attribution and exact negative results, recover valid assets, change the interface only when evidence identifies the missing contract, and require a new bounded gate before upgrading a claim.
