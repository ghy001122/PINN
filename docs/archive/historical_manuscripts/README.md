# Historical Manuscripts

Archived material is retained for provenance, reproducibility, negative evidence, and reviewer defense. It has no current authorization or scientific voting power unless a current authority file explicitly cites a specific artifact and its unchanged claim boundary. Determine current status and permission through the applicable `AGENTS.md` chain, `CODEX_CONTEXT.md`, `docs/research_strategy/active_phase.md`, `PROJECT_STATE.md`, and `NEXT_ACTIONS.md`; the long Q2 execution guide is a versioned design reference only.

`docs/manuscript/main_submission_v1.md`, `main_submission_v2.md`, and their locked figure/table/submission assets remain at original paths because scripts, manifests, and integrity tests reference them. They are logically archived snapshots of the former 1D constrained-inverse route. Do not edit or treat them as the current manuscript. A new version requires an active evidence-to-manuscript route; positive R1 wording requires passed R1 evidence, while a limitation or negative manuscript may use precisely scoped supported or failed-but-informative evidence.
