# Manuscript Versions

`main_submission_v1.md` and `main_submission_v2.md` are protected historical snapshots of the former 1D constrained-inverse route. Their reproducibility and reviewer-defense value remains, but they are logically archived and are not the selected current manuscript.

Do not overwrite v1 or v2. Any new manuscript is separately versioned and created only when `active_phase.md` routes evidence to manuscript synthesis. Positive R1 result wording still requires a positive, gate-complete R1 result; a limitation or negative-result manuscript may instead use supported and precisely scoped failed-but-informative evidence without waiting for that positive gate. Planning language must never be presented as a completed result.

The degradable paper identity is:

1. R1 `HysGeo-Hybrid-PINN`: minimum route;
2. R2 `GeoPhase-HomoMoE-PINN`: preferred method upgrade if matched-budget synergy passes;
3. R3 observable-subspace/OQ: conditional extension only if solver/PINN sensitivity gates pass.

Current manuscript routing comes from `active_phase.md` and `NEXT_ACTIONS.md`. `submission_go_no_go.md` is a dated historical snapshot, not current status. Scientific claim authority remains `docs/paper/final_claim_matrix.md`; historical manuscript paths and lifecycle are indexed by `docs/archive/historical_manuscripts/README.md`.
