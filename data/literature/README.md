# Literature Data Templates

This directory stores literature-ingestion registries, parameter sanity tables,
and digitization queues. Provenance-backed external source payloads and derived
curves belong under `data/external/` with manifests and the ownership rules in
`docs/data_provenance.md`.

Do not add fabricated points. Each curve record must identify its source,
figure/table or dataset location, curve type, units or normalization, extraction
method, license/access boundary, and provenance. Directory contents do not by
themselves authorize fitting or a validation claim; use the current active
contract and claim matrix.
